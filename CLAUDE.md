## Stack
Vite + React 19 + TS strict + Tailwind 4 + shadcn/ui · Zustand + TanStack Query ·
Cloudflare Workers (Hono) + Static Assets · **D1** (Drizzle) · **Durable Objects** (ConversationDO, UserDO, CallDO, RateLimiterDO) ·
**R2** · **KV** · **Queues** · Better Auth (cookie sessions) · WebRTC P2P + Cloudflare Realtime TURN · Cloudflare Email Sending.

## Hard rules
1. **D1 has no RLS.** All authorization lives in `src/server/policy/`. Every route calls a policy function; every policy function has an allow test and a deny test in the same PR. A route with no `policy` import fails CI.
2. Only `src/server/repos/**` may import Drizzle or touch `env.DB`. Routes and Durable Objects go through repos.
3. Every exported repo function takes `actor: Actor` as its first parameter and re-checks authorization itself.
4. Identity comes from the session cookie or `ws.deserializeAttachment()` — **never** from a request body or WS frame field.
5. Request/response shapes are zod schemas in `src/shared/` imported by both the route and the client. Never define a shape twice.
6. Never put `BETTER_AUTH_SECRET`, `R2_SECRET_ACCESS_KEY`, `TURN_API_TOKEN`, or `VAPID_PRIVATE_KEY` in client code or a `VITE_*` var.
7. D1 migrations are generated by `drizzle-kit`, forward-only, and backward-compatible with the deployed Worker (expand → deploy → contract). DO SQLite schema changes are additive-only.
8. Close every `MediaStreamTrack` and `RTCPeerConnection` on all exit paths, including errors and unmount.
9. Durable Objects: `getByName` for routing, WebSocket **Hibernation** API (`ctx.acceptWebSocket`), `blockConcurrencyWhile` for schema init only, persist before mutating in-memory state.
10. Every async UI path handles loading, empty, error, and offline. Never cache authenticated responses in the service worker.
11. No `any`; no `!` non-null assertion without an explanatory comment. New dependency requires a stated justification.

## Commands
```
pnpm dev            # vite + wrangler dev
pnpm build          pnpm typecheck      pnpm lint
pnpm test           # vitest incl. @cloudflare/vitest-pool-workers suites
pnpm test:e2e       # playwright against wrangler dev
pnpm drizzle-kit generate
wrangler d1 migrations apply ripple-local --local
wrangler deploy --env staging
```
